# Login System

A simple Python login system that allows users to register and log in using hashed passwords.

# Features
- Register new users
- Login with username + password
- Passwords stored as SHA‑256 hashes
- Basic authentication logic

# Skills Practiced
- Dictionaries
- Hashing (SHA‑256)
- Functions
- Input validation

## How to Run
```bash
python login_system.py
